# Análise de Dados de Veículos

Este é um aplicativo web desenvolvido com **Streamlit** para análise de dados de veículos. O aplicativo permite a criação de gráficos interativos, como histogramas e gráficos de dispersão, com base nos dados de um arquivo CSV. Ele oferece uma interface simples para explorar o conjunto de dados de veículos, permitindo ao usuário gerar visualizações dinâmicas.

## Funcionalidades

- Visualização interativa de dados de veículos.
- Criação de gráficos dinâmicos:
  - **Histogramas**: Exibe a distribuição dos dados em intervalos.
  - **Gráficos de dispersão**: Exibe a relação entre duas variáveis numéricas.
- Caixa de seleção ou botões para permitir a criação de diferentes tipos de gráficos, conforme a escolha do usuário.
